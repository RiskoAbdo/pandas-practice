# pandas Practice

Personal pandas practice by Occulenz (Abdullah Nabil), in Arabic and English. It follows the sections of the Udemy course "Data Analysis with Pandas and Python": short drills after every topic, a use case at the end of each section, an "everything so far" case, and a capstone with the tips the course does not cover.

Real pandas runs in the browser (Pyodide). Every answer is checked on the visible sample data and on three hidden data sets with the traps real data has.
